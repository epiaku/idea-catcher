## Why You Must Start Writing in Markdown by Eason Blackwood

### Summary

Markdown offers far more flexibility and freedom compared to traditional tools like Microsoft Word and Scrivener. Paired with Obsidian, Markdown creates a future-proof, plain-text foundation that decouples raw content from presentation, making it easier to manage, automate, and publish across multiple formats \[

### Main Purpose

To convince writers—especially self-published authors and indie creators—to switch from proprietary, bloated software to plain-text Markdown so they maintain complete ownership of their intellectual property and streamline publishing automation \[

[00:36](https://www.google.com/search?q=https%3A%2F%2Fwww.youtube.com%2Fwatch%3Fv%3DP9kOBpOY32c%26t%3D36)

### Action Plan

- Audit your current writing tool stack to check if your manuscript files depend on proprietary formats.
- Download a plain-text editor like Obsidian or VS Code.
- Store manuscripts, chapters, and drafts as plain `.md` files inside standard local file folders \[
	[08:05](https://www.google.com/search?q=https%3A%2F%2Fwww.youtube.com%2Fwatch%3Fv%3DP9kOBpOY32c%26t%3D485)
	\].
- Separate raw text drafting from design/layout formatting using frontmatter and metadata \[
	[08:18](https://www.google.com/search?q=https%3A%2F%2Fwww.youtube.com%2Fwatch%3Fv%3DP9kOBpOY32c%26t%3D498)
	\].
- Utilize lightweight exporters or open-source community plugins to compile standard formats like PDF, EPUB, or DOCX on demand \[
	[12:18](https://www.google.com/search?q=https%3A%2F%2Fwww.youtube.com%2Fwatch%3Fv%3DP9kOBpOY32c%26t%3D738)
