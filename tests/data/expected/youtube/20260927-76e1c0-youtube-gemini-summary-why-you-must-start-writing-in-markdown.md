## 📝 Summary

Markdown offers more flexibility than Microsoft Word and Scrivener. Paired with Obsidian, it separates raw content from presentation and supports publishing across multiple formats (00:06).

## 🎯 Main Purpose

Encourage writers, especially self-published authors and indie creators, to switch from proprietary software to plain-text Markdown to maintain ownership of their intellectual property and streamline publishing automation (00:36).

## 💡 Key Examples

- Microsoft Word workflow: writing and formatting become tangled, while separate ebook, print, and submission files create duplicate work (02:05).
- Scrivener workflow: an all-in-one environment with compiling tools illustrates the risk of lock-in and losing access to structured data (05:03).
- Obsidian short story export: a live workspace exports plain-text files into standard Shunn manuscript format using custom scripting (09:36).
- Novel and ebook exporting: desktop scripts transform Markdown files into styled print layouts and ebook formats (10:16).

## ✅ Action Plan

- Audit your writing tools to check whether manuscript files depend on proprietary formats.
- Download a plain-text editor such as Obsidian or VS Code.
- Store manuscripts, chapters, and drafts as plain `.md` files in standard local folders (08:05).
- Separate drafting from design and layout using frontmatter and metadata (08:18).
- Use lightweight exporters or open-source community plugins to compile PDF, EPUB, or DOCX on demand (12:18).

## 💬 Tips

| Tip | Explanation | How to Apply |
| --- | ----------- | ------------ |
| Decouple Content from Presentation | Ideas should exist independently of how they appear on screen or in print (11:12). | Write in plain text with lightweight Markdown structural tags instead of styled Rich Text (08:12). |
| Maintain a Single Source of Truth | Separate manuscript, print, and ebook documents can cause sync errors (03:16). | Keep one master Markdown folder and compile target formats with exporters (09:11). |
| Future-Proof Intellectual Property | Proprietary formats risk lock-in or lost access if software licensing changes or the software is discontinued (07:03). | Store core text locally in open `.md` or `.txt` formats (10:48). |
